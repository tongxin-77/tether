    Tether
    
            
    Windows 上的轻量多会话终端。会话由后台进程持有，关闭窗口不会中断正在运行的任务。
    
            
    在会话里运行 Claude Code，侧栏会实时显示它的状态：思考中、等待确认、子代理运行中、已完成。
    
            
    安装
    
            
    从 Releases 下载 Tether_0.2.0_x64-setup.exe，安装后自动检查更新。
    
            
    开发
    

    pnpm install
pnpm tauri dev
