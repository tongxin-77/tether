Tether

Windows 上的轻量多会话终端。会话由后台进程持有，关掉窗口也不会中断；再次打开时一切还在原处。

特性

  • 本地目录与 SSH 主机会话并排管理
  • 侧栏实时显示 Claude Code 的状态：思考中、等待确认、已完成
  • 内置文件树，支持拖拽上传下载

安装

从 Releases 下载安装包，或使用 winget：

winget install Tether

安装后可在 设置 中开启 Claude Code 集成。
