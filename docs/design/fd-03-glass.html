    Tether

    Windows 上的轻量多会话终端。会话由后台进程持有，关掉窗口也不会中断；重新打开，输出原样还在。

    主要功能

    • 本地目录与 SSH 主机会话并排管理
    • 侧栏实时显示 Claude Code 的状态：思考中、等待确认、子代理运行中、已完成
    • 右侧文件树支持上传、下载与复制文件名
    • 窗口背景透明度可调

    安装

    winget install Tether

    也可以从 Releases 下载 tether_0.2.0_x64-setup.exe，之后的版本会自动更新。
