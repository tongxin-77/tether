README.md

Tether

Windows 上的轻量多会话终端。会话由后台进程持有，关掉窗口也不会中断；重新打开时，一切都还在原处。

主要功能

  • 本地目录与 SSH 主机会话并列管理
  • 侧栏实时显示 Claude Code 的状态：思考中、等待确认、子代理运行中、已完成
  • 右侧文件树，支持拖拽上传与下载

开始使用

安装后点击 ＋ 新建会话，选择一个文件夹即可。也可以在终端中直接运行：

winget install Tether
