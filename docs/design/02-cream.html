Tether

Windows 上的轻量多会话终端。会话由后台进程持有，关掉窗口也不会中断；重新打开，一切都在原处。

在会话里运行 Claude Code，侧栏会实时显示它在思考、等待确认，还是已经完成。

快速开始

winget install Tether
tether .        # 在当前目录新建会话

特性

  • 本地目录与 SSH 主机会话并排管理
  • 右侧文件树支持拖拽上传、下载与 Markdown 预览
  • 自动更新，更新时不打断正在运行的会话

更多用法见 docs/usage.md。
