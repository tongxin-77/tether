Tether

Windows 上的轻量多会话终端。会话由后台进程持有，关掉窗口也不会中断；重新打开即可接着用。

特性

  • 本地目录与 SSH 主机会话并排管理
  • 侧栏实时显示 Claude Code 状态：思考中、等待确认、子代理运行中、已完成
  • 右侧文件树支持拖放上传与下载
  • 窗口背景透明度可调

快速开始

winget install Tether
tether .   # 在当前目录打开会话

更多说明见 docs/usage.md。
