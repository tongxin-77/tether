Tether

Windows 上的轻量多会话终端。会话由后台进程持有，关掉窗口也不会中断。

在会话里运行 Claude Code，侧栏会实时显示它在思考、等待确认，还是已经完成。

特性

  • 多会话：本地目录与 SSH 主机并列管理
  • 后台持有：tether-daemon 保活，重开窗口自动恢复
  • 文件树：浏览、上传下载、复制文件名
  • 自动更新：更新只重启界面，不打断会话

安装

# 从 GitHub Release 下载安装包
winget install tether
# 或从源码构建
pnpm install && pnpm tauri build
